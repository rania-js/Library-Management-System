# Library Management System

A Library Management System developed using **F#**.

## Overview

This project aims to provide a simple system for managing library operations, including adding books, searching for books, borrowing and returning books, and tracking their availability.

The system is designed using Functional Programming concepts in F#, focusing on immutability, records, maps, pattern matching, and error handling.

## Features

- Add new books to the library.
- Search for books by title.
- Borrow available books.
- Return borrowed books.
- Display available and borrowed books.
- Prevent borrowing a book that is already borrowed.
- Track borrowing dates.

## Technologies Used

- **Programming Language:** F#
- **Platform:** .NET
- **Version Control:** Git & GitHub

## Concepts Applied

- Functional Programming
- Records and Discriminated Unions
- Immutable Data Structures
- Maps and Lists
- Pattern Matching
- Result Type for Error Handling
- First-Class Functions

## Project Status

The project is currently under development. Features are being implemented and tested incrementally.
